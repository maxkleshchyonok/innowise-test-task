## Description

A simple calculator app with basic math functions

## Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/en/)
- [npm](https://www.npmjs.com/)

## Installation

```bash
git clone https://github.com/maxkleshchyonok/innowise-test-task
cd innowise-test-task
npm i
```

## Project Structure

```
innowise-test-task/
├── build/                # Production build output
│   └── index.html        # Entry HTML for production
│   └── main.*.js         # Bundled JavaScript for production
├── public/               # Static public assets
│   └── index.html        # Main HTML template for development
├── src/                  # Source code
│   ├── index.js          # App entry point
│   ├── components/       # UI components
│   │   ├── AppControls/  # Controls for the app (HTML, CSS)
│   │   ├── Button/       # Button component (HTML, CSS, JS)
│   │   ├── Calculator/   # Calculator logic and UI (HTML, CSS, JS)
│   │   └── Theme-toggle/ # Theme toggle switch (HTML, CSS, JS)
│   ├── constants/        # App constants
│   ├── styles/           # Global styles
│   └── utils/            # Utility functions (with math logic)
├── package.json          # Project metadata and scripts
├── webpack.config.js     # Webpack configuration
├── eslint.config.js      # ESLint configuration
└── README.md             # Project documentation
```

- **build/**: Contains the production-ready build output generated by Webpack.
- **public/**: Static assets and the main HTML template used during development.
- **src/**: All source code for the app, including components, styles, constants, and utilities.
- **package.json**: Lists dependencies and defines npm scripts.
- **webpack.config.js**: Configuration for building and bundling the app.
- **eslint.config.js**: Linting rules for code quality.
- **README.md**: Project overview and instructions.

### How to run the app

- ```bash
    npm run dev
  ```

  This command starts a development server and opens the app in the default web browser

- ```bash
    npm run build
  ```

  This command compiles the app for production using Webpack

- ```bash
    npm run watch
  ```

  This command watches for file changes and recompiles the app in development mode

- ```bash
    npm run lint
  ```

  This command checks code for linting errors using ESLint

- ```bash
      npm run lint:fix
  ```

  This command automatically fixes linting errors where possible

- ```bash
    npm run format
  ```

  This command formats code using Prettier

- ```bash
      npm run format:check
  ```
  This command checks if the code is properly formatted
